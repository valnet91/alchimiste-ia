# Contrats

- `site.csv` : identité, URL canoniques, compte GitHub.
- `entries.csv` : fiches (intro + 10 contrôles). `a` = champ vide.
- Sortie publique : `README.md` à la racine du dépôt.

Colonnes `entries.csv` :

`schema_version;id;locale;sequence;date_classement;categorie;priorite;emoji;titre;slug;corps;dod;note;state`

`state` : `source` uniquement pour cette première version (FR).
